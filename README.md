# collider.kn5-copy-to-all-folders

## Aim
Copy the legitimate collider.kn5 file to all car folders in Assetto Corsa, allowing you to use all cars without purchasing any DLC.

## Instructions

1. Copy the two provided files to `C:\SteamLibrary\steamapps\common\assettocorsa\content\cars`.

2. Double-click on the batch file. This will replace all existing `collider.kn5` files inside the car folders with your provided file.
